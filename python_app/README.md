# Foxico Travel Carousel - Standalone Python + HTML/CSS Version

This directory provides the exact landing page carousel built strictly using **HTML5, CSS3, and Python 3**, requiring zero TypeScript, Node.js, or external build tools.

## Quick Start (Run with Python)

From the project root:

```bash
python3 app.py
```

Or from within the `python_app` folder:

```bash
cd python_app
python3 -m http.server 8000
```

Then open your browser at:
`http://localhost:8000` (or `http://localhost:3000`)

## Included Features

1. **Top Bar**: Foxico brand wordmark, Fox mascot logo, clean navigation links (News, Destinations, Blog, Contact), search, saved favorites badge, and user avatar.
2. **Left Vertical Rail**: Interactive slide index ("01"), step dots, and total count ("05").
3. **Hero Destination Details**: Bold title (`INDONESIA`, `THAILAND`, `BALI`, `INDIA`, `JAPAN`), description, rating, and "Explore →" call to action.
4. **Interactive Carousel Cards**: Cards on the right ("Buddha temple, Thailand", "Broken Beach, Bali", "Kerala, India", "Mount Fuji, Japan") with 5-star rating, bookmark save toggle, and click-to-activate transitions.
5. **Bottom Navigation**: Circular left/right arrow controls, animated progress bar, and keyboard arrow keys support.
6. **Curated Explorer Drawer**: In-depth destination guide with weather, best season, currency, and highlights.
